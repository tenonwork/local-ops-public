# Security policy

## Reporting a vulnerability

Report vulnerabilities privately through GitHub's security advisories on this repository
("Security" tab -> "Report a vulnerability"). Do not open a public issue, and do not include credentials,
connection strings, or production data in an issue or pull request.

## Scope

This repository is a reference implementation of a Postgres-backed agent workflow. It does not ship
credentials. If you find a configuration in this tree that would expose a real deployment, report it
privately.

## Supported versions

Only the current `main` branch is supported.
